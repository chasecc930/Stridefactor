# Stride Factor

Free running tools for track and cross-country athletes.

Live site: https://stridefactor.net

## Tools
- Race time predictor
- Goal time calculator
- College running recruiting standards
- Training pace calculator
- Race split calculator
- Altitude race time converter

## About
A static website with no build step. Everything runs in the browser. Optional free accounts use Supabase to save PRs and goals.

Predictions are estimates, not guarantees.
